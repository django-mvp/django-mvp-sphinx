# Admonitions

Each kind of admonition takes its colour from the theme: information, help, caution and danger.

```{note}
A note adds something the reader may want to know.
```

```{tip}
A tip helps the reader do something better.
```

```{hint}
A hint points at the answer without giving it away.
```

```{important}
Something the reader mustn't miss.
```

```{seealso}
[daisyUI's alert component](https://daisyui.com/components/alert/), which these are drawn like.
```

```{attention}
Attention asks the reader to stop and read.
```

```{caution}
A caution warns of something that can go wrong.
```

```{warning}
A warning, with `inline code` and a [link](https://daisyui.com), and a list:

- first item
- second item
```

```{danger}
Danger: this deletes data.
```

```{error}
Something has gone wrong.
```

```{admonition} An admonition with its own title
A generic admonition, with a title of its own.
```

```{todo}
A to-do item, shown because `todo_include_todos` is on.
```

:::{note}
An admonition holding a code block:

```python
print("inside an admonition")
```
:::
