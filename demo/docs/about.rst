About this guide
================

This guide describes the demo site, for the people using it. It is not about the
package behind it: what the package does, and how a project uses it, is told in
its `README <https://github.com/django-mvp/django-mvp-sphinx#readme>`_.

It is the one page in the sidebar that belongs to no caption, which keeps it at the
top level, below the groups.
